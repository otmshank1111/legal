Brand Analytics Dashboard

A private internal reporting tool operated by KK SP & All Ghost Labs.

What it does

The dashboard reads performance metrics from social media accounts that we own and operate, and assembles them into weekly reports. It exists so that one person running several brands can see how each is performing without opening five apps and copying numbers by hand.

How it uses TikTok

It connects through TikTok's official Display API, using Login Kit, and only to accounts whose owner has explicitly authorized it. Within the scopes granted, it reads:

  • Basic profile information for the authorized account
  • Aggregate account statistics: follower count, following count, total likes, video count
  • A list of that account's own public posts and their metadata

It is read-only. It does not post, publish, message, follow, or take any other action on a connected account.

Not a public product.

There is no sign-up and no public user base. Access is limited to the operator and people the operator authorizes.

Data handling

Metrics are stored locally on hardware the operator controls and used only to produce internal reports. Nothing is sold, shared, or disclosed to third parties. Authorization can be revoked at any time in TikTok's own settings, which immediately ends all access.
